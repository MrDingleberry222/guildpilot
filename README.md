# GuildPilot Website

Public static showcase for GuildPilot. It contains the animated landing page and does not include the Discord bot or dashboard server.

## View locally

Open `site/index.html` in a browser, or serve the `site` directory with any static web server.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the `site` directory to GitHub Pages whenever changes are pushed to `main`.

The public page is a visual showcase. Discord sign-in, server settings, and bot invites require the GuildPilot application server and Discord credentials; the showcase explains this when those links are selected.
